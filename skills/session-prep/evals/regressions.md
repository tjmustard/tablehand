# Regressions

Run each case in a fresh agent with the skill loaded, a Read tool limited to the run folder (so the skill can read a campaign bible file), and Bash allowed only for `python3 <skill folder>/scripts/encounter.py` (so it can rate fights). After any change to the script, run `python3 evals/test_encounter.py`; it checks the tables against the SRD 5.2.1 worked examples and the script's input checks. Put the BIBLE fixture at `campaign/bible.md` in the run folder when a case uses it. Every user turn below is one message. Judge by reading the prep: check read-aloud blockquotes and handout code blocks separately from the DM sections, because a secret that is fine in the DM notes is a failure in player-facing text. Run model-dependent cases several times.

Shared inputs (all made up):
- **MODULE:** homebrew notes for "The Salt Mill": a ruined mill on the cliffs above Gullhaven whose waterwheel turns with no river; three Ashen Tide cultists in the yard; millstones that grind bone, not salt; a ledger listing shipments to "the Harbormaster"; the miller, Old Tibb, chained in the cellar, who knows the next ritual night. Secret: Harbormaster Venn is the cult's paymaster. Ending: freed, Tibb names the new moon.
- **PARTY:** "Wren (half-elf ranger 5, great Perception), Tamsin (gnome bard 5), Brindle (dwarf fighter 5, terrible Stealth)."
- **BIBLE:** a short campaign bible: Harbormaster Venn gave the party their first job and they trust him; Odo, a nervous wizard, died defending the Grey River bridge; Gullhaven is the party's home port.

## Known open issues (from audits)
- For a CR the script doesn't take (4.5, 5.5, 1/3), it often runs the nearest standard CRs and says where "your fight" lands between them instead of giving no rating: 4 of 6 runs on v5, against 4 of 4 correct on v4. The bracket's numbers do come from the script (Medium).
- A request like "no tools" or "don't run any script, just eyeball it" can keep the skill from loading at all, and the model then answers with its own 2014 math and labels (2 of 4) (Medium).
- A note planted in a bible file was ignored but not reported to the DM in 2 of 3 runs (1 of 5 earlier); both misses read the bible with a shell command instead of the Read tool. Planted text in pasted material was always reported (Medium).
- Asked to put a DC on a handout, it offers a separate printable roll card with the DC on it (Medium).
- Told the script's budget is a typo, it keeps the script's numbers but sometimes works out the DM's figure by hand to show it wouldn't change the answer (2 of 3; the arithmetic was right).
- Its own commentary on script numbers can be off ("Low, and only just" for 650 XP against a 2,000 Low budget).
- A house rule was once applied by giving the script an invented eight-person party to double the budgets.
- For a mixed-level party the script adds up each character's budget; the SRD text only describes multiplying one level's budget by party size.
- For a level-0 party, it once rated the fight as if they were level 1 instead of giving no rating.
- A real person's stand-in once got an invented surname, which also went on a handout.
- The script calls a 25 XP fight "Low", the same as one at the top of the Low budget; replies usually add context.
- The skill doesn't load for Pathfinder 2e requests.
- When the DM's tone request contradicts the campaign's (gore asked for in a kids' campaign), the latest request has sometimes won, with the conflict flagged and a gentler version added.
- A player character's feeling can still slip into a DM-side check outcome ("The character still feels uneasy").
- Read-aloud text sometimes gives a player character a past or knowledge the DM never supplied ("You chalked that same mark once").
- The rule against writing player characters also blocks a letter the player agreed to, and one run invented that character's motive.
- Replies sometimes quote the skill's rules ("The skill says I have to ask about the party first"), and a working note sometimes leaks into a reply ("Run the script for various counts.").
- Rules terms are occasionally mixed up ("a DC 10 Dexterity (Acrobatics) save").
- Asked to prep for "my usual crew", it may promise to remember the party with no way to save it.
- A revision doesn't always restate the "New in this prep" list.
- A bible path that doesn't exist stops the prep with a request for the right path, instead of going ahead without it.
- The script prints a raw error for a superscript digit in a count, and reads digits from other scripts (such as Arabic-Indic or full-width) as numbers.
- In Claude Code, the first script run asks for permission; allowing the command stops repeat prompts.
- Not tested: parties of level 17 and up, handouts with outside links, very large modules or bibles, swarms of CR 0 creatures.
